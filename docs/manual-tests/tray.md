# 트레이 상주·종료 — 손으로 하는 확인

`npm run test:e2e:tray`(test/e2e/tray-check.mjs)가 창 닫기·Dock 클릭(activate)·중복 실행·종료·숨긴 채 동기화를 자동으로 확인한다.
아래는 스크립트로 확인할 수 없는 항목이다(트레이 아이콘을 실제로 누르기, 실제 키 입력, 아이콘 모양).
`npm start`로 띄워 확인하고, 확인한 날짜와 결과를 표에 적는다.

## Windows

| # | 할 일 | 기대 결과 |
|---|---|---|
| 1 | 창의 X를 누른다 | 창이 사라지고 알림 영역(숨겨진 아이콘 칸 ^ 포함)에 파란 ⊕가 남는다 |
| 2 | ⊕를 왼쪽 클릭한다 | 창이 다시 열린다 |
| 3 | ⊕를 오른쪽 클릭한다 | "열기 / 종료" 메뉴가 뜬다. "열기" → 창이 열린다 |
| 4 | 메뉴에서 "종료" | 작업 관리자에서 앱(electron) 프로세스가 없어진다 |
| 5 | 창을 숨긴 채 Windows를 다시 시작한다 | 앱 때문에 종료가 막히지 않는다 |

## macOS

| # | 할 일 | 기대 결과 |
|---|---|---|
| 1 | 빨간 닫기 버튼 또는 Cmd+W | 창이 사라지고 메뉴바의 흑백 ⊕와 Dock 아이콘은 남는다 |
| 2 | Dock 아이콘을 누른다 | 창이 다시 열린다 |
| 3 | 메뉴바 ⊕를 누른다 | "열기 / 종료" 메뉴가 열린다. "열기" → 창 표시 |
| 4 | 메뉴에서 "종료" | 앱이 끝난다(Dock에서 사라짐) |
| 5 | 창이 보일 때 Cmd+Q, 창을 숨겼을 때 Dock 아이콘 오른쪽 클릭 → 종료 | 둘 다 앱이 끝난다 |
| 6 | 밝은·어두운 메뉴바(시스템 설정 → 화면 모드)에서 ⊕를 본다 | 둘 다 잘 보인다(Template 이미지라 OS가 색을 바꾼다) |
